Projeto 01: Análise de Vendas

1. Objetivo do Projeto:
Criar uma base de dados fictícia para simular as vendas de uma loja de tecnologia, calcular indicadores de desempenho e apresentar os resultados de forma visual para apoiar a tomada de decisão.

2. Resultados Principais:

O Faturamento Total do período analisado foi de: R$ 29.200,00

O Ticket Médio (valor médio por venda) foi de: R$ 1.946,67

O vendedor com o melhor desempenho foi Carlos, responsável por um total de R$ 16.600,00.

3. Limitações do Projeto:
Este é um projeto de estudo inicial. Os dados utilizados são fictícios e representam um volume inicial de vendas (15 registos) criados especificamente para a prática de organização, formatação e aplicação de fórmulas (SOMA, MEDIA, SOMASE).
